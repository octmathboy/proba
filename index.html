Exercice 1 : Densité, Espérance, Variance et Extremums

Variables Continues
1
Conditions de densité et valeur de $k$
💡 Explication $f$ est une densité de probabilité si et seulement si $f(x) \ge 0$ sur $\mathbb{R}$ et $\displaystyle \int_{-\infty}^{+\infty} f(x)\,dx = 1$.

• Positivité : $x^2 \ge 0$ sur $[-1, 1]$ et $f(x)=0$ ailleurs, donc il faut $k \ge 0$.

• Normalisation :

$$\int_{-1}^{1} kx^2\,dx = k \left[ \frac{x^3}{3} \right]_{-1}^{1} = k \left(\frac{1}{3} - \left(-\frac{1}{3}\right)\right) = \frac{2}{3}k = 1 \implies k = \frac{3}{2}$$
$\mathbf{k = \frac{3}{2}}$ (condition $k \ge 0$ vérifiée)
2
Tracé sommaire du graphe de $f$
💡 Explication Sur $[-1, 1]$, c'est une parabole de sommet $(0,0)$ qui monte jusqu'à $f(-1) = f(1) = 1,5$. Ailleurs, la fonction est nulle sur l'axe des abscisses.
3
Réponses possibles, Espérance $E(X)$ et Variance $V(X)$
💡 Logique avant calcul $X \in [-1, 1]$ et $f$ est paire (symétrique autour de $0$), donc $E(X) \in [-1, 1]$ et vaut exactement $0$. De plus, une variance est toujours positive ($V(X) \ge 0$) et bornée par $1^2 = 1$ sur $[-1, 1]$.
✘ a) $2 < E(X) < 3$ (hors $[-1,1]$)
✔ b) $-1 \le E(X) \le 1$ (vrai)
✘ c) $E(X)=0,5$ (non symétrique)
✔ d) $E(X)=0$ (centre de symétrie)
✘ e) $V(X)=-0,5$ (jamais négative)
✘ f) $V(X)=2$ (trop grande)
✔ g) $V(X)=0,5$ (plausible $\in [0,1]$)
$$E(X) = \int_{-1}^{1} x \cdot \frac{3}{2}x^2\,dx = \frac{3}{2} \left[\frac{x^4}{4}\right]_{-1}^{1} = 0$$ $$V(X) = E(X^2) - [E(X)]^2 = \int_{-1}^{1} x^2 \cdot \frac{3}{2}x^2\,dx - 0 = \frac{3}{2} \left[\frac{x^5}{5}\right]_{-1}^{1} = \frac{3}{2}\left(\frac{2}{5}\right) = \frac{3}{5} = 0,6$$
Possibles : b), d), g)  |  $\mathbf{E(X) = 0}$  |  $\mathbf{V(X) = 0,6}$
4-5
Fonction de répartition $F_X(x)$ et calcul de $P(-0,5 \le X \le 0,5)$

4. Fonction de répartition $F_X(x) = \int_{-\infty}^{x} f(t)\,dt$ :

  • Si $x < -1$ : $F_X(x) = 0$.
  • Si $-1 \le x \le 1$ : $\displaystyle F_X(x) = \int_{-1}^{x} \frac{3}{2}t^2\,dt = \frac{3}{2}\left[\frac{t^3}{3}\right]_{-1}^{x} = \frac{x^3 + 1}{2}$.
  • Si $x > 1$ : $F_X(x) = 1$.

5. Calcul de probabilité :

$$P(-0,5 \le X \le 0,5) = F_X(0,5) - F_X(-0,5) = \frac{0,125 + 1}{2} - \frac{-0,125 + 1}{2} = \frac{0,25}{2} = 0,125$$
$\mathbf{P(-0,5 \le X \le 0,5) = 0,125}$
6-7
Lois du Maximum $Z = \sup X_i$ et du Minimum $T = \inf X_i$
💡 Astuce Extremums • $\sup X_i \le z \iff$ tous les $X_i \le z$ (on utilise l'indépendance).
• $\inf X_i > t \iff$ tous les $X_i > t$ (on passe par le complémentaire $1 - P(T > t)$).

6. Pour $Z = \sup_{1 \le i \le n} X_i$ :

$$F_Z(z) = P(X_1 \le z, \dots, X_n \le z) = \prod_{i=1}^n P(X_i \le z) = [F_X(z)]^n$$

Sur $[-1, 1]$, $F_Z(z) = \left(\frac{z^3+1}{2}\right)^n$. En dérivant : $\displaystyle f_Z(z) = \frac{3n}{2}z^2\left(\frac{z^3+1}{2}\right)^{n-1}$ (et $0$ ailleurs).

7. Démarche pour $T = \inf_{1 \le i \le n} X_i$ :

$$P(T > t) = P(X_1 > t, \dots, X_n > t) = \prod_{i=1}^n [1 - F_X(t)] = [1 - F_X(t)]^n \implies F_T(t) = 1 - [1 - F_X(t)]^n$$

On obtient ensuite $f_T(t)$ en dérivant $F_T(t)$ par rapport à $t$.

Exercice 2 : Loi Normale et Lecture de Table

Loi Normale $\mathcal{N}(m, \sigma^2)$
1-2
Loi normale centrée réduite $T \sim \mathcal{N}(0, 1)$
💡 Propriétés de la fonction de répartition $\Phi(t) = P(T \le t)$ • Symétrie : $\Phi(-t) = 1 - \Phi(t)$.
• Intervalle centré : $P(-a \le T \le a) = 2\Phi(a) - 1$.

1. Calculs directs via la table de $\mathcal{N}(0, 1)$ :

  • $P(T \le 1,42) = \Phi(1,42) \approx \mathbf{0,9222}$
  • $P(T \le -1,42) = 1 - \Phi(1,42) = 1 - 0,9222 = \mathbf{0,0778}$
  • $P(-1 \le T \le 1) = 2\Phi(1) - 1 = 2(0,8413) - 1 = \mathbf{0,6826}$
  • $P(-2 \le T \le 2) = 2\Phi(2) - 1 = 2(0,9772) - 1 = \mathbf{0,9544}$
  • $P(-1,96 \le T \le 1,96) = 2\Phi(1,96) - 1 = 2(0,9750) - 1 = \mathbf{0,9500}$

2. Lecture inverse :

  • $P(T < t) = 0,8859 \implies$ lecture directe dans la table : $\mathbf{t \approx 1,205}$ (ou $1,20$ / $1,21$ selon table).
  • $P(T < t) = 0,0718 < 0,5 \implies t$ est négatif. On cherche $1 - 0,0718 = 0,9282 = \Phi(1,46)$, donc $\mathbf{t \approx -1,46}$.
3
Centrage-réduction avec $X \sim \mathcal{N}(m=178, \sigma^2=25)$
💡 Changement de variable Attention : $\sigma^2 = 25 \implies \sigma = \sqrt{25} = 5$. On pose $T = \frac{X - 178}{5} \sim \mathcal{N}(0, 1)$.
  • $P(X \le 173) = P\left(T \le \frac{173 - 178}{5}\right) = P(T \le -1) = 1 - \Phi(1) = 1 - 0,8413 = \mathbf{0,1587}$
  • $P(X > 188) = P\left(T > \frac{188 - 178}{5}\right) = P(T > 2) = 1 - \Phi(2) = 1 - 0,9772 = \mathbf{0,0228}$
  • $P(173 < X \le 188) = P(-1 < T \le 2) = \Phi(2) - \Phi(-1) = 0,9772 - 0,1587 = \mathbf{0,8185}$
4-5
Règle des sigmas et détermination de $(m, \sigma)$

4. Formule générale :

$$P(m - t\sigma < X \le m + t\sigma) = P(-t < T \le t) = 2P(T < t) - 1$$
  • Pour $t=1$ : $P(m-\sigma < X \le m+\sigma) = 2(0,8413) - 1 = \mathbf{0,6826}$ (68,3%)
  • Pour $t=2$ : $P(m-2\sigma < X \le m+2\sigma) = 2(0,9772) - 1 = \mathbf{0,9544}$ (95,4%)
  • Pour $t=3$ : $P(m-3\sigma < X \le m+3\sigma) = 2(0,9987) - 1 = \mathbf{0,9974}$ (99,7%)

5. Système d'équations pour trouver $m$ et $\sigma$ :

  • $P(X < 8) = 0,1587 \implies P\left(T < \frac{8 - m}{\sigma}\right) = 1 - 0,8413 \implies \frac{8 - m}{\sigma} = -1 \implies m - \sigma = 8$
  • $P(X < 14) = 0,9772 \implies P\left(T < \frac{14 - m}{\sigma}\right) = 0,9772 \implies \frac{14 - m}{\sigma} = 2 \implies m + 2\sigma = 14$

Par soustraction des deux équations : $3\sigma = 6 \implies \sigma = 2$, d'où $m = 8 + 2 = 10$.

$\mathbf{m = 10}$ et $\mathbf{\sigma = 2}$

Exercice 3 : Retards des Trains & Approximations

Binomiale $\to$ Poisson $\to$ Normale
1
Loi exacte de $X$ sur $n = 100$ trains
💡 Justification On répète $n = 100$ épreuves de Bernoulli indépendantes (chaque train est en retard avec probabilité $p = 0,05$, ou non avec $q = 0,95$). $X$ compte le nombre de succès.
  • Loi : $X \sim \mathcal{B}(n = 100, p = 0,05)$
  • Espérance : $E(X) = np = 100 \times 0,05 = \mathbf{5}$
  • Écart type : $\sigma(X) = \sqrt{np(1-p)} = \sqrt{100 \times 0,05 \times 0,95} = \sqrt{4,75} \approx \mathbf{2,18}$
2
Approximation par la loi de Poisson
💡 Conditions d'approximation Binomiale $\to$ Poisson $n$ est grand ($n = 100 \ge 30$), $p$ est petit ($p = 0,05 \le 0,1$) et $np = 5 < 10$. On approche $\mathcal{B}(100, 0,05)$ par la loi de Poisson $\mathcal{P}(\lambda = np = 5)$.
$$P(X = 3) \approx e^{-\lambda} \frac{\lambda^3}{3!} = e^{-5} \frac{5^3}{6} = \frac{125}{6} e^{-5} \approx 20,833 \times 0,006738 \approx \mathbf{0,1404}$$
3
Passage à $n = 1000$ trajets : Approximation par la Loi Normale
💡 Conditions + Correction de continuité Ici $n = 1000 \ge 30$, $np = 50 \ge 5$ et $nq = 950 \ge 5$ (et $npq = 47,5 > 10$). Par le TCL, $X$ suit approximativement $\mathcal{N}(m = 50, \sigma^2 = 47,5)$ avec $\sigma = \sqrt{47,5} \approx 6,892$.
Pour passer d'une variable discrète à une continue, on applique la correction de continuité ($\pm 0,5$).
  • Calcul de $P(X = 50)$ : $$P(49,5 \le X \le 50,5) = P\left(\frac{-0,5}{6,892} \le T \le \frac{0,5}{6,892}\right) = P(-0,07 \le T \le 0,07) = 2\Phi(0,07) - 1 = 2(0,5279) - 1 = \mathbf{0,0558}$$
  • Calcul de $P(40 < X \le 60) = P(41 \le X \le 60)$ :

    Avec correction de continuité, l'intervalle devient $[40,5 \,;\, 60,5]$ :

    $$P(40,5 \le X \le 60,5) = P\left(\frac{40,5 - 50}{6,892} \le T \le \frac{60,5 - 50}{6,892}\right) = P(-1,38 \le T \le 1,52)$$ $$= \Phi(1,52) - [1 - \Phi(1,38)] = 0,9357 - (1 - 0,9162) = 0,9357 - 0,0838 = \mathbf{0,8519}$$

Exercice 4 : Loi Faible des Grands Nombres

Convergence en Probabilité
1
Espérance, Variance et Écart type de la moyenne empirique $\overline{X}_n$
  • Espérance (par linéarité) : $$E(\overline{X}_n) = E\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n}\sum_{i=1}^n E(X_i) = \frac{1}{n}(n \cdot m) = \mathbf{m}$$
  • Variance (par indépendance des $X_i$) : $$V(\overline{X}_n) = V\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n^2}\sum_{i=1}^n V(X_i) = \frac{1}{n^2}(n \cdot \sigma^2) = \mathbf{\frac{\sigma^2}{n}}$$
  • Écart type : $$\sigma(\overline{X}_n) = \sqrt{V(\overline{X}_n)} = \mathbf{\frac{\sigma}{\sqrt{n}}}$$
2-3
Convergence en probabilité vers $m$ et généralisation
💡 Critère suffisant de convergence en probabilité (Inégalité de Bienaymé-Tchebychev) Si $\lim_{n \to +\infty} E(Y_n) = c$ et $\lim_{n \to +\infty} V(Y_n) = 0$, alors $Y_n \xrightarrow{\mathbb{P}} c$.

2. Démonstration :

On a $E(\overline{X}_n) = m$ (constant) et $\lim_{n \to +\infty} V(\overline{X}_n) = \lim_{n \to +\infty} \frac{\sigma^2}{n} = 0$. D'après l'inégalité de Bienaymé-Tchebychev, pour tout $\varepsilon > 0$ :

$$P(|\overline{X}_n - m| \ge \varepsilon) \le \frac{V(\overline{X}_n)}{\varepsilon^2} = \frac{\sigma^2}{n\varepsilon^2} \xrightarrow[n \to +\infty]{} 0$$

Donc $\overline{X}_n$ converge en probabilité vers $m$.

3. Si les $X_i$ n'ont plus la même loi mais gardent la même espérance $m$ et la même variance $\sigma^2$ :

Oui, le résultat reste parfaitement vrai ! Dans les calculs précédents, nous n'avons jamais utilisé le fait que les $X_i$ aient la même loi, uniquement leur indépendance, $E(X_i) = m$ et $V(X_i) = \sigma^2$.

Exercice 5 : Lancers d'un Dé & Test d'Hypothèse Intuitif

Loi Binomiale & TCL
1
Loi de $X$ sur $n = 720$ lancers

Les $720$ lancers sont indépendants et la probabilité d'obtenir le chiffre 6 à chaque lancer est constante ($p = 1/6$). Donc :

  • Loi : $X \sim \mathcal{B}\left(n = 720, p = \frac{1}{6}\right)$
  • Espérance : $E(X) = 720 \times \frac{1}{6} = \mathbf{120}$
  • Variance : $V(X) = 720 \times \frac{1}{6} \times \frac{5}{6} = \mathbf{100}$
  • Écart type : $\sigma(X) = \sqrt{100} = \mathbf{10}$
2
Calcul de $P(X = 120)$ par deux méthodes normales

• Formule exacte (Binomiale) : $\displaystyle P(X = 120) = C_{720}^{120} \left(\frac{1}{6}\right)^{120} \left(\frac{5}{6}\right)^{600}$.

• Conditions d'approximation Normale : $n = 720 \ge 30$, $np = 120 \ge 5$, $nq = 600 \ge 5$. On approche $X$ par $\mathcal{N}(m = 120, \sigma^2 = 100)$.

• Méthode 1 (via la densité de probabilité) :

$$P(X = 120) \approx f(120) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(120-120)^2}{2\sigma^2}} = \frac{1}{10\sqrt{2\pi}} \approx \frac{1}{25,066} \approx \mathbf{0,0399}$$

• Méthode 2 (via la fonction de répartition + correction de continuité) :

$$P(119,5 \le X \le 120,5) = P\left(\frac{-0,5}{10} \le T \le \frac{0,5}{10}\right) = P(-0,05 \le T \le 0,05) = 2\Phi(0,05) - 1 = 2(0,5199) - 1 = \mathbf{0,0398}$$
3
Interprétation de l'observation : 150 apparitions du chiffre 6
💡 Raisonnement statistique Si le dé était équilibré, $99,7\%$ des résultats se situeraient dans $[m - 3\sigma, m + 3\sigma] = [120 - 30, 120 + 30] = [90, 150]$.

Calculons la probabilité d'observer un résultat au moins aussi extrême que $150$ sous l'hypothèse d'un dé équilibré :

$$P(X \ge 150) \approx P\left(T \ge \frac{149,5 - 120}{10}\right) = P(T \ge 2,95) = 1 - \Phi(2,95) = 1 - 0,9984 = \mathbf{0,0016} \text{ (soit } 0,16\%\text{)}$$
Conclusion : La probabilité qu'un dé équilibré donne $150$ fois le chiffre 6 est quasi nulle ($0,16\%$). Vos soupçons sont fondés : le dé est très probablement pipé !

Exercice 6 : Assurance Maritime & Somme de Lois de Poisson

Loi de Poisson $\mathcal{P}(\lambda)$
1-2
Loi exacte de $N$, approximation de Poisson et comparaison

1. Loi exacte : $n = 200$ navires indépendants, probabilité d'accident $p = 0,002$. Donc $N \sim \mathcal{B}(200 \,;\, 0,002)$.

2. Approximation : $n = 200 \ge 30$, $p = 0,002 \le 0,1$ et $\lambda = np = 200 \times 0,002 = 0,4 < 10$. On approche $N$ par la loi de Poisson $\mathcal{P}(\lambda = 0,4)$.

Paramètre Loi Binomiale $\mathcal{B}(200 \,;\, 0,002)$ Loi de Poisson $\mathcal{P}(0,4)$
Espérance $E(N)$ $np = 0,4$ $\lambda = 0,4$ (Identique)
Variance $V(N)$ $np(1-p) = 0,4 \times 0,998 = 0,3992$ $\lambda = 0,4$ (Très proche)
3
Probabilités d'accidents durant un an ($N \sim \mathcal{P}(0,4)$)

On utilise $P(N = k) = e^{-0,4} \frac{(0,4)^k}{k!}$ avec $e^{-0,4} \approx 0,67032$ :

  • Aucun accident : $P(N = 0) = e^{-0,4} \approx \mathbf{0,6703}$
  • Un accident : $P(N = 1) = 0,4 \cdot e^{-0,4} \approx \mathbf{0,2681}$
  • Deux accidents : $P(N = 2) = \frac{0,4^2}{2!} e^{-0,4} = 0,08 \cdot e^{-0,4} \approx \mathbf{0,0536}$
  • Strictement plus de deux accidents ($N > 2$) : $$P(N > 2) = 1 - [P(N=0) + P(N=1) + P(N=2)] = 1 - (0,6703 + 0,2681 + 0,0536) = \mathbf{0,0080}$$
4
Nombre d'accidents $Z = X + Y$ sur deux ans

(a) Décomposition de l'événement $\{Z = 2\}$ :

Puisque $X$ et $Y$ sont indépendantes et suivent $\mathcal{P}(0,4)$ :

$$\{Z = 2\} = \{X + Y = 2\} = (\{X=0\} \cap \{Y=2\}) \cup (\{X=1\} \cap \{Y=1\}) \cup (\{X=2\} \cap \{Y=0\})$$ $$P(Z = 2) = P(X=0)P(Y=2) + P(X=1)P(Y=1) + P(X=2)P(Y=0)$$ $$= (0,6703 \times 0,0536) + (0,2681 \times 0,2681) + (0,0536 \times 0,6703) = 0,0359 + 0,0719 + 0,0359 = \mathbf{0,1437}$$

(b) Méthode rapide par théorème (Stabilité de la loi de Poisson) :

La somme de deux variables aléatoires indépendantes suivant des lois de Poisson $\mathcal{P}(\lambda_1)$ et $\mathcal{P}(\lambda_2)$ suit une loi de Poisson $\mathcal{P}(\lambda_1 + \lambda_2)$. Ici, $Z = X + Y \sim \mathcal{P}(0,4 + 0,4) = \mathcal{P}(0,8)$ :

$$P(Z = 2) = e^{-0,8} \frac{(0,8)^2}{2!} = 0,32 \cdot e^{-0,8} \approx 0,32 \times 0,44933 \approx \mathbf{0,1438}$$
